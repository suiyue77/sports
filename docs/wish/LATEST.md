# Current Wish · Sports

让读者能在排球、健身和棒球的基础知识与练习建议之间快速定位，并以官方规则和活动指南核对事实；不把它做成实时比分、个人健康档案或个性化医疗/训练处方。

**Preserve:** source credibility, straightforward navigation, mobile use and the visitor's ability to complete the central task. A new aesthetic or implementation must make that task easier, not simply add decoration.

Feature goals and current/better design: [Feature Design](../design/features/README.md). This is part of Design, not a separate governance owner.
